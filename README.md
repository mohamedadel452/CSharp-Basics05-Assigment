### 🧠 الملاحظات الهندسية والمفاهيم المعمارية (Engineering Notes)
1. **حدود الرؤية ومحددات الوصول (`Access Modifiers`):**
   - `private`: يحجب الحقل (`password`) عن أي كود خارج الكلاس نفسه لحماية الحالة الداخلية (Encapsulation).
   - `internal`: يتيح الوصول للحقل (`copiesInStock`) لأي كلاس داخل نفس الـ **Assembly** (المشروع الحالي)، ويمنع الوصول إليه من المشاريع الخارجية.
   - `public`: يشكل العقد العلني للكلاس (`Title`, `BookGenre`).
2. **تمثيل الـ `Enum` والتحويلات الآمنة (`Genre Enum`):**
   - الـ `Enum` هو نوع قيمة (`Value Type`) يرتبط افتراضياً بنوع `int` (`Fiction = 0`, `NonFiction = 1`, `Science = 2`).
   - التحويل بين `Genre` و `int` يتم عبر Explicit Cast بتكلفة صفرية في الذاكرة.
   - عند تحويل مدخلات نصية إلى `Enum`، استخدام `Enum.TryParse("Mystery", out Genre result)` يمنع رمي استثناءات `ArgumentException` ويتيح التعامل الآمن مع القيم غير المعرفة.
