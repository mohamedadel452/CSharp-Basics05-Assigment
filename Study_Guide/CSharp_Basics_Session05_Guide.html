2. تشريح الـ Enum والتحويلات الآمنة (Q4 – Q9)

الـ enum Genre { Fiction, NonFiction, Science } هو Value Type يعتمد تحت السطح افتراضياً على نوع صحيح int (حيث Fiction = 0، NonFiction = 1، Science = 2) ولا يستهلك أي حجز في الـ Heap إلا عند عمل Boxing.

  • التحويل بين Enum و int (Q5 & Q6): يتم عبر Explicit Cast مباشر مثل (int)Genre.Science أو (Genre)1 بتكلفة صفرية في وقت التشغيل.
  • تحويل النص إلى Enum بأمان (Q8 vs Q9): استخدام Enum.Parse<Genre>(text) يرمي استثناء ArgumentException إذا كان النص غير معروف (مثل "Mystery" أو اختلاف حالة الأحرف بدون IgnoreCase)، بينما Enum.TryParse(invalidGenreText, out Genre result) يحمي التطبيق من الانهيار ويعيد false بأمان.
